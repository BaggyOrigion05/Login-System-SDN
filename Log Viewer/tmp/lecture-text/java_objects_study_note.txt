public class Student {
    private String studentNumber;
    private String name;
    private String surname;
    public Student(String studentNumber,
                   String name, String surname) {
        this.studentNumber = studentNumber;
        this.name = name;
        this.surname = surname;
    }
    public String getStudentNumber() {
        return studentNumber;
    }
    public String getName() {
        return name;
    }
    public String getSurname() {
        return surname;
    }
}
1  Instance variables store the information
In private String name;, String is the type and name is the field name. private limits direct access from other
classes.
2  The constructor sets the starting information
Student(...) has the same name as the class and no return type. It runs when new Student(...) creates an
object. In this.name = name;, this.name is the object's field; name is the value passed in.
3  Getters return information
getName() returns this object's name. Reading it does not remove it from the object. A getter is a method;
the parentheses mean we call it.
