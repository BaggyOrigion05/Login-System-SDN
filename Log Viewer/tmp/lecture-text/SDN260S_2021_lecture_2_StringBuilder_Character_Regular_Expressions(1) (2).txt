Class StringBuilder 
• Strings in Java are immutable (i.e. unmodifiable)
• StringBuilder class provided for creating and manipulating modifiable
strings
• String vs. StringBuilder: use:
– String when objects will not change
– StringBuilder when objects will need to change (e.g. insert, delete, concatenate,
etc.)

• Operations we may wish to make on StringBuilder objects:
– Determine number of characters:
• s1.length();
– Determine how many characters can be stored without allocating additional memory:
• s1.capacity();
– Set minimum capacity:
• s1.ensureCapacity(int);
– Increase/decrease length:
• s1.setLength(int)
– Extract single character:
• s1.charAt(idx);
– Extract sequence of characters:
• s1.getChars(idx1, idx2, charArray, idx3);
– Replace specified character with given character argument:
• s1.setCharAt(idx, char);
– Reverse the contents:
• s1.reverse();

Regular Expressions 
• Regular expression:
– A specially formatted String (can’t be StringBuilder) that describes a search
pattern for matching characters in other Strings
– Consists of literal characters and special symbols
– Useful for validating input and ensuring that data is in a particular format
• Some special symbols predefined for use in regular expressions:
– Digit (\d): any numeric character (\D: any nondigit)
– Word (\w): any letter, digit or underscore character (\W: any nonword)
– Whitespace ( \s): space, tab, carriage return, newline, form feed ( \S: any
nonwhitespace)
• Various operators/special characters are combined to form complex
regular expression patterns
14 

Regular Expressions 
• Use square brackets [ ] to match any (single of a) set of (the bracketed) 
characters that do not have predefined special characters 
– [aeiou] matches a single vowel character 
– [A-Z] matches a single uppercase letter 
– [A-Za-z] matches a single uppercase or lowercase character 
– [A-z] matches any letter and all characters with integer value between 
uppercase Z and lowercase a 
• [^Z] matches any character that’s not a Z 
• (abcd) matches the string “abcd” 
• (abcd¦efgh) matches “abcd” or “efgh” 
• Quantifiers: 
– (charSequence)* matches zero or more occurrences of “charSequence” 
– (charSequence)? matches zero or one occurrence of “charSequence” 
– (charSequence)+ matches one or more occurrences of “charSequence” 
– (charSequence){n,m} matches between n and m (inclusive) occurrences of 
“charSequence” 
– (charSequence){n} matches exactly n occurrences of “charSequence” 
– (charSequence){n,} matches at least n occurrences of “charSequence” 15

Regular Expressions 
• Methods used in conjunction with regular expressions:
– s1.matches(“regex”) matches regex with s1 content; returns true if all of s1
matches regex, false otherwise
– s1.replaceAll(“regex”, “s2”) replaces every occurrence in s1 matching regex
with s2
– s1.replaceFirst(“regex”, “s2”) replaces first occurrence in s1 matching regex
with s2
– s1.split(“regex”) splits s1 based on regex (can be comma, whitespace, etc);
returns an array of Strings

Classroom Exercise 
• Design a Java application that will request a student user to enter his/her
information, as follows:
– First name(s)
– Last name
– Student number
• The application will then display (on separate lines) the student’s:
– Initials and surname
– Student number
– Student email address
• Validate the student number  to ensure it lies in the range: 200000001-
229999999; if student number entered is invalid, the application should inform
the user and repeatedly prompt the user to re-enter a valid one
• For example, if the student enters first name(s)  (Wandile Lloyd ); last name
(Botha); student number (211111111), the application will display the information
as follows:
– Initials and surname: WL Botha
– Student number: 211111111
– Student email: 21111111@mycput.ac.za
